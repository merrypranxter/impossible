# Maximalism With Structure

This repo is allowed to be maximalist as hell.
But the maximalism must have bones.

## Bad maximalism

- random rainbow noise
- every effect active at once
- no spatial anchor
- no readable room
- no central law
- no emotional target

## Good maximalism

- one clear room
- one dominant impossible law
- several secondary effects that obey or contrast the law
- palette hierarchy
- fog depth
- material behavior
- a symbolic threshold
- a camera that witnesses rather than merely rotates

## The law-first method

Before adding detail, write:

```text
This room is impossible because __________.
```

If that sentence is weak, the shader will be weak.

Examples:

- This room is impossible because the hallway repeats but the gravity vector rotates every module.
- This room is impossible because the pool surface behaves like an event horizon.
- This room is impossible because the camera and the walls disagree about which direction is forward.
- This room is impossible because the portal is not a doorway but a coordinate remapping wound.
