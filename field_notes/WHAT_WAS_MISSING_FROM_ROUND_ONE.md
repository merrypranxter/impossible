# What Was Missing From Round One

Round one had the skeleton:
- repo structure
- initial 12 rooms
- shader basics
- core docs
- Copilot seed agent

Round two adds the missing organs.

## Missing: ontology

Without an ontology, Copilot may treat the repo as a grab bag.
Now it has a conceptual taxonomy: rooms, domains, constraints, witnesses, thresholds, hauntings.

## Missing: camera theory

Raymarched worlds are often ruined by neutral cameras.
Impossible architecture needs a camera personality.

## Missing: fog discipline

Fog is not garnish.
Fog is world glue, scale fraud, mood, and error concealment.

## Missing: material logic

Materials should reveal which wrong law affected them.
Otherwise the rooms become generic procedural surfaces.

## Missing: portals as coordinate contracts

A portal is not just a glowing oval.
It is a disagreement between coordinate systems.

## Missing: debugging rituals

Wrong-physics shaders break constantly.
Debug views are mandatory if this repo is going to grow without becoming cursed sludge.

## Missing: expansion tasks

The repo now contains explicit Copilot jobs so it can grow in useful directions.
