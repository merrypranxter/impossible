# Room Grammar

Use this grammar to generate coherent impossible rooms.

## Syntax

```text
[architecture noun] + [domain operation] + [physics violation] + [sensory atmosphere] + [threshold symbol]
```

## Examples

```text
vestibule + mirror fold + gravity drift + wet violet fog + triangular mouth
chapel + sphere inversion + backwards light + dust bloom + eye altar
hotel + modular repetition + memory loop + stale yellow haze + numbered doors
atrium + hyperbolic scale + horizon failure + glassy blue fog + spiral window
```
