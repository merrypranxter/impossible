# Image Prompt Engine: Impossible Rooms

Use this when turning the repo into image prompts.

## Base prompt skeleton

```text
A raymarched impossible liminal room called [ROOM TITLE], built from [MATH TRICK], where [WRONG PHYSICS]; [MOOD]; [PALETTE]; procedural SDF architecture, glowing fog volumes, recursive spatial distortion, shader-art lighting, impossible geometry, navigable haunted math, volumetric mood weather, chromatic aberration, edge glow, non-Euclidean spatial tension, no technical overlay.
```

## Merry-flavored maximalist version

```text
A cursed raymarched shader-world called [ROOM TITLE], a haunted navigable math chamber built from [MATH TRICK], where [WRONG PHYSICS]. The architecture is not designed, it is computed wrong on purpose: recursive rooms, soft boolean walls, fog volumes behaving like a nervous system, symbolic portals with collision detection, chromatic edge-glow, greasy neon reflections, impossible vanishing points, wrong-gravity floor logic, liminal backrooms energy but dressed in psychedelic velvet and shader noise. Palette: [PALETTE]. No diagrams, no labels, no grid overlays, no boring-ass tech demo energy.
```

## Variables

- `[ROOM TITLE]`
- `[MATH TRICK]`
- `[WRONG PHYSICS]`
- `[MOOD]`
- `[PALETTE]`
- `[CAMERA BEHAVIOR]`
- `[FOG BEHAVIOR]`
- `[PORTAL/SYMBOL BEHAVIOR]`
