# Expansion Roadmap

## Phase 1 — Starter rooms

The 12 included rooms establish the grammar:

1. fold
2. twist
3. invert
4. soft boolean
5. ray-bent gravity
6. polar portal
7. recursion
8. moiré fog
9. curvature warp
10. anti-physics water
11. structural glyph
12. hyperbolic backrooms seed

## Phase 2 — sdf_liminal_architecture

Add 12 more rooms, each based on one architectural archetype:

- laundromat cathedral
- motel hallway
- hospital waiting room
- mall fountain after closing
- airport terminal with no departures
- dead arcade
- church basement
- school hallway at 2am
- fluorescent office maze
- cosmic bathroom
- basement stairs
- empty pool chamber

## Phase 3 — hyperbolic_backrooms

Focus on:

- exponential depth compression
- hallway recursion
- impossible floor plans
- wallpaper as topology
- rooms that contain their own entrances
- visibility horizons
- non-Euclidean navigation cues

## Phase 4 — dream_physics merge

Add rules where:

- gravity responds to color
- doors open into weather
- surfaces remember being touched
- signs and symbols become collision objects
- scale changes with emotional proximity
- camera FOV dilates with “panic”

## Phase 5 — Shadertoy release pack

Create:

- `shadertoy/room_01_folded_vestibule.glsl`
- `shadertoy/room_02_twist_stairwell.glsl`
- stripped-down versions using `mainImage(out vec4 fragColor, in vec2 fragCoord)`
- notes for which uniforms map to Shadertoy’s `iResolution`, `iTime`, `iMouse`

## Phase 6 — p5.js / Three.js bridge

Create:

- p5 wrapper for WebGL shader loading
- Three.js full-screen quad renderer
- CPU-side camera/controller module
- screenshot/capture manager

## Phase 7 — Agentic repo growth

- new room branches
- metadata entries
- lore docs
- prompt modules
- performance variants
- ASCII maps
- image prompt packs
