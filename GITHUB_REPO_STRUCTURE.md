# GITHUB REPO STRUCTURE

This repository is designed as a creative shader-art knowledge base and working demo pack.

## Purpose

`impossible` collects code, grammar, prompts, and study notes for **raymarched worlds with wrong physics**.

It should help generate:

- WebGL2 shader sketches
- Shadertoy fragments
- p5.js / Three.js shader ports
- AI art prompts
- video prompts
- music prompts
- Copilot-generated room expansions
- SDF/raymarching recipe files

## Important folders

- `standalone/`: self-contained HTML demos.
- `src/`: reusable shader/harness/CSS source.
- `worlds/`: one lore/implementation doc per room.
- `recipes/`: how-to files for SDF tricks.
- `glsl_modules/`: copy-paste shader snippets.
- `prompts/`: creative prompt engines.
- `agents/`: Copilot agent instructions.
- `data/`: room metadata and grammars.
- `docs/`: repo map, principles, roadmap, sources.

## Expansion rule

Do not add random snippets without context. Every new shader idea should become at least:

1. a named room or module
2. a markdown explanation
3. a reusable code snippet or standalone demo
4. a prompt translation if visually useful
